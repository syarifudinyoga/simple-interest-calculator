# Simple Interest Calculator

A simple interest calculator created for the final project.

## Description

This project calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Calculate simple interest
- Simple bash script
- Easy to use

## Technologies Used

- Bash
- Git
- GitHub

## Usage

Run the script using:

```bash
bash simple-interest.sh
```

## Example

If:
- Principal = 1000
- Rate = 5
- Time = 2 years

Then:

Simple Interest = 100
